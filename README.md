# 🧩 Proyecto: Herencia, @Override y uso de super en Java

## 👤 Autor
Oscar David Castillo Boteo

## 📚 Descripción
Este proyecto implementa los conceptos fundamentales de la Programación Orientada a Objetos (POO) en Java, haciendo uso de:

- Herencia (`extends`)
- Sobreescritura de métodos (`@Override`)
- Uso de `super` para reutilizar constructores y métodos

Se desarrollan 10 ejercicios prácticos que simulan diferentes escenarios del mundo real.

---

## 🏗️ Estructura del Proyecto

El proyecto está dividido en los siguientes ejercicios:

### 1️⃣ Persona, Docente, Estudiante
- Uso de herencia básica
- Sobreescritura del método `mostrar()`

### 2️⃣ Cuenta y CuentaCorriente
- Implementación de sobregiro con límite

### 3️⃣ Producto y ProductoPerecedero
- Manejo de productos con fecha de vencimiento

### 4️⃣ Transporte y Bus
- Representación de transporte con capacidad y ruta

### 5️⃣ Empleado y Gerente
- Cálculo de salario con bonificación

### 6️⃣ Animal y Perro
- Polimorfismo con sonidos

### 7️⃣ Vehiculo y Moto
- Uso de `super` para heredar atributos

### 8️⃣ Figura, Rectangulo y Circulo
- Cálculo de áreas utilizando polimorfismo

### 9️⃣ Libro y LibroDigital
- Extensión de funcionalidad con atributos adicionales

### 🔟 Sistema de Facturación
- Clases:
  - Cliente
  - Factura
  - FacturaContado (descuento)
  - FacturaCredito (recargo y cuotas)

---

## ⚙️ Funcionalidades principales

- Aplicación de herencia entre clases padre e hijas
- Uso de `@Override` para modificar comportamientos
- Uso de `super` para reutilización de código
- Implementación de lógica de negocio en cada ejercicio
- Ejecución completa desde la clase `Main`
